# Token Usage Feature - Test Specification Summary

## Overview
This test specification covers the **token-used feature** in the Atom codebase, which tracks LLM API token consumption for monitoring costs and usage across conversations.

## Feature Description
The token-used feature tracks:
- **Input tokens** (`tokensIn`): Tokens sent to the LLM (context + prompt)
- **Output tokens** (`tokensOut`): Tokens generated by the LLM
- **Cost** (`cost`): USD cost of the API call
- **Cache tokens** (optional): `cacheRead` and `cacheWrite` for providers supporting prompt caching

Token data is stored at the **message level** in the database and exposed through:
1. Database persistence (message table)
2. Event emissions (`step-finish` events)
3. Part data (StepFinishData type)
