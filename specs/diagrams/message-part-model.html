Quark architecture

Message + Part model

A message is the stable conversation envelope. Parts are the content and runtime events inside that envelope, persisted as append-only snapshots and replayed into either model context or UI state.

Message is the envelope

MessageRow stores identity, role, provider/model metadata, finish reason, token usage, and timestamps.

Part is the payload

PartRow stores typed content or runtime metadata. Tool and text parts can be appended repeatedly with the same part id.

Replay chooses the shape

toModelMessages() builds AI SDK context; TUI/Web projections build visible chat parts and skip runtime-only metadata.

Concrete example

One turn with a tool call

User asks for files. The assistant writes text, calls a tool, then stores the tool result. Notice how the tool part keeps the same partId while its data changes.

1. JSONL events written

{
  type: "message",
  messageId: "m_user",
  role: "user"
}
{
  type: "part",
  messageId: "m_user",
  partId: "p_user_text",
  partType: "text",
  data: { text: "List files" }
}
{
  type: "message",
  messageId: "m_asst",
  role: "assistant"
}
{
  type: "part",
  messageId: "m_asst",
  partId: "p_tool",
  partType: "tool",
  data: { tool: "bash", status: "awaiting_approval" }
}
{
  type: "part",
  messageId: "m_asst",
  partId: "p_tool",
  partType: "tool",
  data: { tool: "bash", status: "completed", output: "README.md\nsrc" }
}

2. Rows after replay

messages = [
  { id: "m_user", role: "user", finish: "stop" },
  { id: "m_asst", role: "assistant", finish: "tool-calls" }
]

parts = [
  {
    id: "p_user_text",
    messageId: "m_user",
    type: "text",
    data: { text: "List files" }
  },
  {
    id: "p_tool",
    messageId: "m_asst",
    type: "tool",
    data: { tool: "bash", status: "completed", output: "README.md\nsrc" }
  }
]

// The earlier p_tool snapshot was overwritten.

3. Model replay shape

[
  { role: "user", content: "List files" },
  {
    role: "assistant",
    content: [
      {
        type: "tool-call",
        toolCallId: "call_1",
        toolName: "bash",
        input: { cmd: "ls" }
      }
    ]
  },
  {
    role: "tool",
    content: [
      {
        type: "tool-result",
        toolCallId: "call_1",
        output: { type: "text", value: "README.md\nsrc" }
      }
    ]
  }
]

4. UI projection

[
  {
    role: "user",
    parts: [
      { type: "text", text: "List files" }
    ]
  },
  {
    role: "assistant",
    parts: [
      {
        type: "tool",
        tool: "bash",
        status: "completed",
        output: "README.md\nsrc"
      }
    ]
  }
]
