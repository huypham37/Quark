Device Code OAuth — Pi ↔ ChatGPT Subscription

RFC 8628 Device Authorization flow — no browser on the Pi machine needed
Objective
After this you'll understand the Device Code Flow (RFC 8628) — Pi's headless authentication method for ChatGPT subscriptions. Unlike browser OAuth, the user authenticates on a separate device (phone, another computer) by visiting a URL and entering a short code. Pi polls OpenAI's servers until the user completes login, then exchanges the resulting authorization code for tokens.
Step 1
Request Device Code
Pi POSTs to:

auth.openai.com/api/accounts/
deviceauth/usercode

Body: {"client_id": "app_EMoam..."}

No PKCE yet — PKCE is handled server-side by OpenAI for device code.
→
Step 2
Receive Code + Show User
OpenAI responds with:

• device_auth_id — internal session ID
• user_code — short code the user types
• interval — suggested poll interval

Pi displays to the user:
Go to auth.openai.com/codex/device
Enter code: ABCD-1234
Expires in 15 minutes
→
Step 3
User Authenticates Elsewhere
On a different device (phone, laptop), the user opens:

auth.openai.com/codex/device

They enter the user_code and log into their ChatGPT account.

Meanwhile, Pi polls the token endpoint every ~5 seconds, checking if the user has completed authorization.
→
Step 4
Polling Loop
Pi POSTs to:

auth.openai.com/api/accounts/
deviceauth/token

Body: {"device_auth_id": "...", "user_code": "..."}

Possible responses:
• 403/404 → still waiting
• slow_down → add 5s to interval
• 200 OK → success! (returns auth code + verifier)
• timeout → 15 minutes elapsed
→
Step 5
Authorization Code Returned
When polling succeeds, OpenAI returns:

• authorization_code
• code_verifier

Note: Unlike browser OAuth, OpenAI generates the PKCE pair server-side — the verifier is returned along with the auth code. Pi uses both to exchange for tokens.
→
Step 6
Exchange for Tokens
Same token exchange as browser flow:

POST auth.openai.com/oauth/token
grant_type=authorization_code
code=<auth_code>
code_verifier=<server_verifier>
redirect_uri=.../deviceauth/callback

→ access_token + refresh_token
→ Extract chatgpt_account_id from JWT
→ Save to ~/.pi/auth.json
